# Organise random effects for use in [`occARU()`](https://mhollanders.github.io/occARU/reference/occARU.md)

Specify Gaussian process (GP) random effects in occARU models, with a
choice of kernel and whether to estimate species-level length-scales.

## Usage

``` r
make_random(random, K)
```

## Arguments

- random:

  A named list of random effects.

- K:

  Number of seasons
