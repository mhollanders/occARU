# occARU ggplot2 theme

A clean ggplot2 theme used by occARU plotting functions. Can also be
applied to custom plots with `+ theme_occARU()`.

## Usage

``` r
theme_occARU(base_size = 11, base_family = "")
```

## Arguments

- base_size:

  Base font size in pts. Default: `11`.

- base_family:

  Base font family. Default: `""`.

## Value

A `ggplot2` theme object.
